# شاه شو — Achaemenid Reign

پروژه‌ی React + TypeScript، بر پایه‌ی موتورِ مهندسیِ معکوس‌شده‌ی Reigns با محتوایِ ۸۸۳ کارتِ اختصاصیِ هخامنشی.

## ساختار پوشه‌ها

```
src/
  data/         خروجیِ JSON تولیدشده از اکسل (کارت‌ها، افکت‌ها، اهداف، شخصیت‌ها)
  engine/       موتورِ اصلیِ بازی — پارسِ شرط/دلتا/زنجیره، انتخابِ کارت، اعمالِ تصمیم
  economy/      فرمولِ اقتصادِ سکه، قیمتِ ابیلیتی‌ها، پک‌های خرید (تأییدشده)
  db/           لایه‌ی ذخیره‌سازیِ محلی (IndexedDB via Dexie)
  components/   کامپوننت‌های مشترک (آیکون‌ها)
  screens/      صفحاتِ UI (Home, ReignStart, MainGame, Death, Progress, Shop, Settings)
  styles/       تم/پالتِ رنگیِ تأییدشده
scripts/
  generate_cards.mjs   تبدیلِ raw JSON اکسل به src/data/*.json
design/
  ui_preview.html      موکاپِ کاملِ همه‌ی صفحات (مرجعِ بصری)
```

## راه‌اندازی

```bash
npm install
npm run dev       # سرورِ توسعه
npm run build     # ساختِ نسخه‌ی نهایی در dist/
npm run gen:cards # بازتولیدِ src/data/*.json از rows اکسل (در صورتِ تغییرِ دیتا)
```

## داده‌ی منبع

فایل‌های خامِ `cards_raw.json`, `effects_raw.json`, `objectives_raw.json`, `bearers_raw.json`
در ریشه‌ی پروژه، خروجیِ مستقیمِ `Achaemenid_FINAL_fixed (2)-2.xlsx` هستند.
اسکریپتِ `scripts/generate_cards.mjs` این‌ها را به فرمتِ تایپ‌شده در `src/data/` تبدیل می‌کند.

## منطقِ موتور

مطابقِ `Achaemenid_Engine_Spec.md` (مهندسیِ معکوسِ کاملِ Reigns):
- سن/سال با هر کارتِ غیردوئل یک واحد بالا می‌رود
- گرامرِ `conditions`: `and`, `!X`, `X>N`, بولین ساده
- گرامرِ `custom`: فلگ‌ها (`X_keep`)، شمارنده‌ها (`nb_X+`)، افزودن/حذفِ شخصیت (`add_X`/`del_X`)، زنجیره‌سازی (`>`, `>_X`)
- مقادیرِ عددی: `?` (تصادفی بینِ دو عدد یا بدون‌اثر تک‌عددی)، `*` (فقط تزئینی)، `lock` (قفلِ شاخص)

## اقتصادِ سکه (نهایی، تأییدشده)

- فرمول: `coins/year = 4/5/6/8/10/12/14` بر اساسِ بازه‌ی سنی + پاداشِ آستانه
- برگردوندنِ کارت = ۱۰۰ سکه | جانِ اضافه = ۳۵۰ سکه
- پک‌ها: ۲۰۰۰/۹۹هزار، ۳۷۵۰/۱۷۹هزار، ۵۵۰۰/۲۴۹هزار تومان

## وضعیتِ فعلی / محدودیت‌ها

- پرداختِ واقعی (IAP) پیاده‌سازی نشده — دکمه‌های خرید فعلاً مستقیم سکه شبیه‌سازی می‌کنند؛ برای انتشارِ واقعی باید به درگاهِ پرداختِ ایرانی (مثلِ زرین‌پال) وصل شود.
- مینی‌گیم‌های دوئل/مقبره/تخته‌نرد فقط در `design/ui_preview.html` طراحیِ بصری شده‌اند؛ منطقِ تعاملی‌شان هنوز در کد پیاده‌سازی نشده.
- تصویرِ شخصیت‌ها placeholder است (ایموجی/رنگِ ساده)؛ باید با آثارِ واقعی جایگزین شود.
